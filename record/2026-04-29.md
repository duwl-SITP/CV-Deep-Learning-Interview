## 1. SAM2

### A. Backbone

Backbone使用Hiera。Hiera使用MAE的方式进行训练，MAE（Masked Autoencoder）是一种自监督视觉预训练方法，它将图像划分为若干 patch，并随机遮挡其中大部分，只把少量可见部分送入编码器，再通过解码器去重建被遮挡的内容。由于模型必须根据不完整的信息恢复整体结构，它会被迫学习到更具语义性的全局表示，而不是简单的局部纹理特征。这种“遮挡-重建”的训练方式不依赖人工标注，同时计算效率也较高。

![](hiera.png)

[MViTv2](https://arxiv.org/abs/2112.01526)是 Hiera 所衍生的基础分层架构。MViTv2 在其四个阶段学习多尺度表示：它开始时以小通道容量但高空间分辨率建模低级特征，然后在每个阶段用通道容量换取空间分辨率，以便在更深的层中建模更复杂的高级特征。

下表列出了作者为创建 Hiera 对 MViTv2 所做的所有更改，以及每项更改如何影响图像和视频的准确性和速度。

- **将相对位置嵌入替换为绝对位置嵌入**：MViTv2在每个block中都使用相对位置嵌入替换了原始的绝对位置嵌入。Hiera作者认为虽然可以实现一个与稀疏预训练兼容的相对位置编码，但是会增加很多复杂性。所以作者采用了更为简单高效的绝对位置嵌入。对于图像，作者使用正态分布初始化的可学习的位置嵌入。对于视频，作者在时间和空间维度分别使用正态分布初始化了连个可学习的位置嵌入，最后将二者相加得到最终的位置嵌入。实验结果证明，Hiera使用的绝对位置编码比MViTv2的相对位置编码速度更快、性能更好。

- **移除卷积**：作者首先用最大池化层替换每个卷积层，这在最初会降低准确性，因为它对图像特征有巨大的影响。然而，他们发现可以移除其中一些额外的最大池化层，特别是步幅为 1 的层，因为它们基本上是对每个特征图应用 ReLU。通过这样做，作者的准确性几乎恢复到之前的水平，同时将图像的速度提高了 22%，视频的速度提高了 27%。

### B. Memory attention

利用过去帧的特征与预测结果，以及任何新的 prompt，对当前帧的特征进行条件化。

具体来说，作者堆叠了 $L$ 个 Transformer block，其中第一个 block 的输入是当前帧的图像编码（image encoding）。

每个 block 的结构包括：

1. **Self-Attention（自注意力）**
2. **Cross-Attention（交叉注意力）**
    - 注意对象是 memory bank 中存储的内容：
        - 过去帧（无论是否带 prompt）的记忆特征
        - object pointers（对象指针，后文会介绍）
3. **MLP（前馈网络）**

作者在 self-attention 和 cross-attention 中都采用了标准的 attention 操作。

#### B.1 Memory Encoder

Memory encoder（记忆编码器）的作用是生成 memory。具体做法是：先使用一个卷积模块对输出 mask 进行下采样，然后将其与来自 image encoder 的无条件帧特征（unconditioned frame embedding, 原始图像经过Image Encoder的输出）进行逐元素相加，之后再通过轻量级卷积层对这些信息进行融合。

#### B.2 Memory Bank

Memory bank（记忆库）用于保存视频中目标对象过去预测的信息。它维护了两个 FIFO（先进先出）队列：一个保存最近最多 $N$ 帧的 memory，另一个保存最多 $M$ 个带 prompt 的帧的信息。举例来说，在视频目标分割（VOS）任务中，初始 mask 是唯一的 prompt，因此 memory bank 会始终保留第一帧的 memory，同时再保存最近最多 $N$ 个无 prompt 帧的 memory。这两类 memory 都以空间特征图（spatial feature maps）的形式存储。

除了空间 memory 外，系统还会保存一组 object pointers（对象指针），它们是轻量级向量，用于表示待分割目标的高层语义信息。这些 object pointers 来源于每一帧 mask decoder 的输出 token。memory attention 在进行 cross-attention 时，会同时关注空间 memory 特征以及这些 object pointers。

对于最近的 $N$ 帧 memory，模型会加入时间位置编码（temporal positional encoding），从而能够建模目标的短期运动；但对于带 prompt 的帧 memory，则不会加入时间位置信息。原因在于：prompted frames 提供的训练信号更加稀疏，而且在实际推理时，prompted frames 的时间跨度可能远超训练时见到的范围（比如第 1 帧点了一下目标，
第 100 帧用户又纠正一次，推理时间跨度可能远大于训练时的时间跨度），因此加入时间位置信息会降低泛化能力。
