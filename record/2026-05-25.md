## 1. Qwen3-VL RoPE介绍

### A. RoPE

Qwen3-VL中RoPE实现方式并不是将相邻两个维度视为一对，`rotate_half`将向量分为前半部分和后半部分，假设输入向量 $x$ 只有 **4 个特征维度**，即 $x = [x_0, x_1, x_2, x_3]$。

$$
\begin{aligned}
x'_0 &= x_0\cos\theta_0 - x_2\sin\theta_0 \\
x'_1 &= x_1\cos\theta_1 - x_3\sin\theta_1 \\
x'_2 &= x_2\cos\theta_0 + x_0\sin\theta_0 \\
x'_3 &= x_3\cos\theta_1 + x_1\sin\theta_1
\end{aligned}
$$

即：

$$
\begin{bmatrix}
x_{0}^{'} \\
x_{2}^{'} \\
x_{1}^{'} \\
x_{3}^{'}
\end{bmatrix}

= 

\begin{bmatrix}
\cos(\theta_{0}) & -\sin(\theta_{0}) & 0 & 0\\
\sin(\theta_{0}) & \cos(\theta_{0}) & 0 & 0\\
0 & 0 & \cos(\theta_{1}) & -\sin(\theta_{1}) \\
0 & 0 & \sin(\theta_{1}) & \cos(\theta_{1})\\ 
\end{bmatrix}

\begin{bmatrix}
x_{0} \\
x_{2} \\
x_{1} \\
x_{3}
\end{bmatrix}
$$

$$ θ_{i}​=10000^{−\frac{2i}{d}} $$​
``` python
def rotate_half(x):
    """Rotates half the hidden dims of the input."""
    x1 = x[..., : x.shape[-1] // 2]
    x2 = x[..., x.shape[-1] // 2 :]
    return torch.cat((-x2, x1), dim=-1)
    
def get_1d_rope_cos_sin(seq_len, dim, device=None, base=10000.0):
    # dim 必须为偶数
    inv_freq = 1.0 / (
        base ** (
            torch.arange(0, dim // 2, device=device, dtype=torch.float32)
            / (dim // 2)
        )
    )

    position = torch.arange(
        seq_len,
        device=device,
        dtype=torch.float32,
    )

    # [seq_len, dim / 2]
    freqs = torch.outer(position, inv_freq)

    # 前后两半使用相同角度，以匹配 rotate_half
    # [seq_len, dim]
    freqs = torch.cat([freqs, freqs], dim=-1)

    return freqs.cos(), freqs.sin()
    
def apply_rotary_pos_emb_vision(
    q: torch.Tensor, k: torch.Tensor, cos: torch.Tensor, sin: torch.Tensor
) -> tuple[torch.Tensor, torch.Tensor]:
    orig_q_dtype = q.dtype
    orig_k_dtype = k.dtype
    q, k = q.float(), k.float()
    cos, sin = cos.unsqueeze(-2).float(), sin.unsqueeze(-2).float()
    q_embed = (q * cos) + (rotate_half(q) * sin)
    k_embed = (k * cos) + (rotate_half(k) * sin)
    q_embed = q_embed.to(orig_q_dtype)
    k_embed = k_embed.to(orig_k_dtype)
    return q_embed, k_embed
```
