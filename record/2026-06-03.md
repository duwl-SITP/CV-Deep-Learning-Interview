## 1. Qwen3-VL Forword介绍

下方代码是 `Qwen3VLVisionModel` 类的forward函数。

``` python
    def forward(
        self, hidden_states: torch.Tensor, grid_thw: torch.Tensor, **kwargs: Unpack[TransformersKwargs]
    ) -> tuple | BaseModelOutputWithDeepstackFeatures:
        """
        Args:
            hidden_states (`torch.Tensor` of shape `(seq_len, hidden_size)`):
                The final hidden states of the model.
            grid_thw (`torch.Tensor` of shape `(num_images_or_videos, 3)`):
                The temporal, height and width of feature shape of each image in LLM.

        Returns:
            `torch.Tensor`: hidden_states.
        """
        bilinear_indices, bilinear_weights = get_vision_bilinear_indices_and_weights(
            grid_thw,
            num_grid_per_side=self.num_grid_per_side,
            spatial_merge_size=self.config.spatial_merge_size,
            kwargs=kwargs,
        )
        position_ids = get_vision_position_ids(grid_thw, self.spatial_merge_size, kwargs=kwargs)
        cu_seqlens = get_vision_cu_seqlens(grid_thw, kwargs=kwargs)

        hidden_states = self.patch_embed(hidden_states)
        pos_embeds = (self.pos_embed(bilinear_indices) * bilinear_weights[:, :, None]).sum(0)
        hidden_states = hidden_states + pos_embeds.to(hidden_states.dtype)
        rotary_pos_emb = self.rotary_pos_emb(position_ids)

        seq_len, _ = hidden_states.size()
        hidden_states = hidden_states.reshape(seq_len, -1)
        rotary_pos_emb = rotary_pos_emb.reshape(seq_len, -1)
        emb = torch.cat((rotary_pos_emb, rotary_pos_emb), dim=-1)
        position_embeddings = (emb.cos(), emb.sin())

        deepstack_feature_lists = []
        for layer_num, blk in enumerate(self.blocks):
            hidden_states = blk(
                hidden_states,
                cu_seqlens=cu_seqlens,
                position_embeddings=position_embeddings,
                **kwargs,
            )
            if layer_num in self.deepstack_visual_indexes:
                deepstack_feature = self.deepstack_merger_list[self.deepstack_visual_indexes.index(layer_num)](
                    hidden_states
                )
                deepstack_feature_lists.append(deepstack_feature)

        merged_hidden_states = self.merger(hidden_states)

        return BaseModelOutputWithDeepstackFeatures(
            last_hidden_state=hidden_states,
            pooler_output=merged_hidden_states,
            deepstack_features=deepstack_feature_lists,
        )
```

### 1.1 

`get_vision_bilinear_indices_and_weights` 的作用是对每个视觉 token，找到它在固定大小位置表 `elf.pos_embed` 里的 4 个邻近位置，也就是双线性插值的四个角点，并给出这 4 个角点的权重。

``` python
# 当前输入的 h x w 网格，要均匀投到固定的 side x side 位置编码表上。
h_grid = torch.linspace(0, side - 1, h)
w_grid = torch.linspace(0, side - 1, w)
```

对于 `h_grid` 和 `w_grid` 计算 `floor向下取整` 、 `ceil向下取整` 以及 `frac小数部分` 。进而计算出双线性插值所需要的左上、右上、左下、右下坐标。

`get_vision_position_ids`为视觉 Token 生成二维位置坐标 `(row, col)`，供 2D RoPE（Rotary Position Embedding）使用。将原来的二维 Patch 网格重新按照 `merge_size × merge_size` 的块（block）进行重排，然后按 block 顺序展开。

``` python
hpos_ids = torch.arange(h, device=device).unsqueeze(1).expand(-1, w)
hpos_ids = hpos_ids.reshape(h // merge_size, merge_size, w // merge_size, merge_size).transpose(1, 2).flatten()

wpos_ids = torch.arange(w, device=device).unsqueeze(0).expand(h, -1)
wpos_ids = wpos_ids.reshape(h // merge_size, merge_size, w // merge_size, merge_size).transpose(1, 2).flatten()
position_ids.append(torch.stack([hpos_ids, wpos_ids], dim=-1).repeat(t, 1))
```

`cu_seqlens` 是“packed attention 里每个样本的边界”。返回的是一个前缀和数组，比如 `[0, 64, 128, 200, ...]` 这种形式。它告诉 attention：扁平化后的整条hidden_states 里，哪些 token 属于第一个图像/帧，哪些属于下一个。随后在视觉 attention 里直接传给Flash Attention。

### 1.2

`self.patch_embed` 进行时间、空间维度的PatchEmbedding。

`self.pos_embed(bilinear_indices) * bilinear_weights[:, :, None]` 从已有的固定位置 embedding 表中查出双线性插值所需的 4 个邻居位置向量。

后续 pos_embed 是加到 token 表示本身上的绝对二维位置编码。它直接改变每个 patch token 的 hidden_states，让 token 自身携带“我大概在图像哪个绝对区域”的信息。这个信息会进入后面的 LayerNorm、MLP、attention value path、merger 等所有分支。也就是说，pos_embed 改的是 token feature 本体。

RoPE 是作用在 attention 的 query/key 上的位置编码。RoPE 主要影响 attention score，也就是 token 和 token 之间怎么根据相对/二维位置关系互相看见。它不直接加到 value_states 上，也不直接作为一个特征向量留在 hidden state 里。

### 1.3
