## 1. YOLO11

### 1.1 网络改进

#### A. C3K2模块

在C3K2模块是C2F模块的改进，当c3k参数为False时，C3K2模块就是C2F模块。

下面的示意图展示了C2F模块的结构。

``` python 
"""
C2F模块
输入  
↓  
1x1 conv  
↓  
split  
├── shortcut  
├── bottleneck1 ── 中间特征
├── bottleneck2 ── 中间特征 
├── bottleneck3 ── 中间特征 
...  
↓  
concat 所有中间特征  
↓  
1x1 conv
"""
```

相较于C2F模块，C3K2模块就是将bottleneck模块更改为C3K模块，而C3K模块继承自C3模块，重写了C3模块的`self.m`，可以自由修改卷积核尺寸。

``` python
class C3k(C3):
    """C3k is a CSP bottleneck module with customizable kernel sizes for feature extraction in neural networks."""

    def __init__(self, c1: int, c2: int, n: int = 1, shortcut: bool = True, g: int = 1, e: float = 0.5, k: int = 3):
        """
        Initialize C3k module.

        Args:
            c1 (int): Input channels.
            c2 (int): Output channels.
            n (int): Number of Bottleneck blocks.
            shortcut (bool): Whether to use shortcut connections.
            g (int): Groups for convolutions.
            e (float): Expansion ratio.
            k (int): Kernel size.
        """
        super().__init__(c1, c2, n, shortcut, g, e)
        c_ = int(c2 * e)  # hidden channels
        # self.m = nn.Sequential(*(RepBottleneck(c_, c_, shortcut, g, k=(k, k), e=1.0) for _ in range(n)))
        self.m = nn.Sequential(*(Bottleneck(c_, c_, shortcut, g, k=(k, k), e=1.0) for _ in range(n)))
```

#### B. C2PSA模块

C2PSA模块与C2F模块类似，但不会保留所有中间特征。其中，PSA(Position-Sensitive Attention)是一个“通道分裂式注意力模块”：一部分特征直接保留原始信息，另一部分经过 `Attention + FFN` 增强全局依赖后再融合输出。它的核心是在不显著增加计算量的前提下，引入类似 Transformer 的全局建模能力。

``` python
class C2PSA(nn.Module):
    """
    C2PSA module with attention mechanism for enhanced feature extraction and processing.

    This module implements a convolutional block with attention mechanisms to enhance feature extraction and processing
    capabilities. It includes a series of PSABlock modules for self-attention and feed-forward operations.

    Attributes:
        c (int): Number of hidden channels.
        cv1 (Conv): 1x1 convolution layer to reduce the number of input channels to 2*c.
        cv2 (Conv): 1x1 convolution layer to reduce the number of output channels to c.
        m (nn.Sequential): Sequential container of PSABlock modules for attention and feed-forward operations.

    Methods:
        forward: Performs a forward pass through the C2PSA module, applying attention and feed-forward operations.

    Notes:
        This module essentially is the same as PSA module, but refactored to allow stacking more PSABlock modules.

    Examples:
        >>> c2psa = C2PSA(c1=256, c2=256, n=3, e=0.5)
        >>> input_tensor = torch.randn(1, 256, 64, 64)
        >>> output_tensor = c2psa(input_tensor)
    """

    def __init__(self, c1: int, c2: int, n: int = 1, e: float = 0.5):
        """
        Initialize C2PSA module.

        Args:
            c1 (int): Input channels.
            c2 (int): Output channels.
            n (int): Number of PSABlock modules.
            e (float): Expansion ratio.
        """
        super().__init__()
        assert c1 == c2
        self.c = int(c1 * e)
        self.cv1 = Conv(c1, 2 * self.c, 1, 1)
        self.cv2 = Conv(2 * self.c, c1, 1)

        self.m = nn.Sequential(*(PSABlock(self.c, attn_ratio=0.5, num_heads=self.c // 64) for _ in range(n)))

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        Process the input tensor through a series of PSA blocks.

        Args:
            x (torch.Tensor): Input tensor.

        Returns:
            (torch.Tensor): Output tensor after processing.
        """
        a, b = self.cv1(x).split((self.c, self.c), dim=1)
        b = self.m(b)
        return self.cv2(torch.cat((a, b), 1))
```

### 1.2 Loss设计

#### A. Box Loss

Box Loss采用CIoU损失函数，CIoU结合了中心点距离和长宽bi惩罚，损失函数公式为：

$$
CIoU = IoU - \frac{\rho^{2}(b, b^{gt})}{c^{2}} -\alpha (arctan(\frac{w_{gt}}{h_{gt}}) - arctan(\frac{w_{pred}}{h_{pred}}))^{2}
$$
#### B. Cls Loss

Cls Loss采用交叉熵损失函数。

#### C. DFL Loss

DFL Loss用于回归预测框与真实框的偏移，避免了以往L1损失函数需要回归连续值的问题。DFL Loss预测偏移的数据分布，如下表所示。

| GT  | bin | prob | Pred | bin | prob |
| --- | --- | ---- | ---- | --- | ---- |
|     | 3   | 0.3  |      | 3   | 0.2  |
|     | 4   | 0.7  |      | 4   | 0.6  |

训练时：

``` python
GT： 3.7
则：
l, r = 3, 4
计算权重：
wr = 3.7 - 3 = 0.7
wl = 1 - 0.7 = 0.3
```

做交叉熵
$$L = -w_{l}log(p_{l})-w_{r}log(p_{r})$$
推理时，通过数学期望计算出最后预测的偏移距离。
