## 1. QLoRA

对于一个预训练的大模型权重，QLoRA 首先使用 `4-bit NormalFloat` 量化模型权重。

普通均匀 4-bit 量化通常会把范围从 `[-1, 1]` ，权重均匀划分为16个等级，比如`-1.00, -0.87, -0.73, ..., 0.73, 0.87, 1.00`。但是大模型权重往往大量集中在0附近，因此均匀量化会浪费很多表示能力。

`NormalFloat` 假设预训练权重近似服从零均值正态分布：$W \sim \mathcal{N}(0,\sigma^{2})$ 。例如，对于标准正态分布 $\mathcal{N}(0,1)$ ，4 bit 有 $2^{4}=16$ 个可表示值，这16个数在0附近更加密集，在远离0的位置更加稀疏。

```text
[-1.0, -0.6961928009986877, -0.5250730514526367, -0.39491748809814453, -0.28444138169288635, -0.18477343022823334, -0.09105003625154495, 0.0, 0.07958029955625534, 0.16093020141124725, 0.24611230194568634, 0.33791524171829224, 0.44070982933044434, 0.5626170039176941, 0.7229568362236023, 1.0]
```

具体实现时，先将一个Block的权重用Block的最大值缩放到 $[-1, 1]$，这个最大值被称为 **缩放常数** ，再将每个归一化权重量化到距离最近的NF4 量化值，即上面的16个数之一。后续只存储缩放常数和量化值索引。

4-bit 量化通常是按 block 进行的。每个 block 需要一个 scale 或 quantization constant。例如 block size 为 64 时，如果每个 block 存一个 FP32 scale，那么平均每个参数额外需要：

$$32/64=0.532 / 64 = 0.532/64=0.5$$

bit 的开销。

QLoRA 的 **Double Quantization** 做法是：对量化常数本身再进行一次量化，二次量化后每个参数额外开销降至0.127。

然后QLoRA冻结量化后模型权重，加入 `LoRA Adapter`。QLoRA 的权重是 4-bit 存储，但不是直接用 4-bit 做矩阵乘法。实际运算时反量化为BF16，执行 16-bit 矩阵乘法。训练时，梯度不会更新原始 4-bit 主干模型，而是只更新 LoRA adapter。
